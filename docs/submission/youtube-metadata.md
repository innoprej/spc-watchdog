## Title

SPC Watchdog — It Watches, Investigates, and Learns

## Description

SPC Watchdog is an autonomous quality engineer for manufacturing lines.

This three-minute demonstration shows:

- deterministic statistical process monitoring;
- transparent multi-hop root-cause investigation;
- row-level evidence verification;
- a human-reviewed playbook change; and
- a measured smarter re-run that reduces six evidence calls to four.

The factory, incidents, and replay data are entirely synthetic. The simulation clock and deterministic replay are labeled on screen.

Source code and credential-free replay:
https://github.com/innoprej/spc-watchdog
