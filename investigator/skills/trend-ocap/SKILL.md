# Trend OCAP

This is OCAP version 1 for deterministic trend incidents.

1. Load `chart_context` and state the Rule 3 trend already established by WATCH.
2. Check recent equipment records first. Eliminate a recent adjustment or maintenance event only when returned rows support that conclusion.
3. If recent equipment events do not explain the trend, inspect material genealogy and confirm any suspect lot with incoming inspection.
4. If those checks do not explain the trend, use professional judgment and the remaining registered evidence sources.
5. Conclude with separate cited claims for eliminated and implicated hypotheses.

If a registered evidence source proves important but this playbook did not direct you to it, propose one concise new playbook step grounded in the returned rows. Place that source immediately after the nearest necessary preliminary check and before unrelated evidence branches so an approved version avoids unnecessary calls. Do not name a cause until a registered tool returns it.
