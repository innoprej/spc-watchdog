# Mean-shift OCAP

This is OCAP version 1 for deterministic mean-shift incidents.

1. Load `chart_context` and state the signal already established by WATCH.
2. Check recent equipment records first. Eliminate equipment only when the returned status and detail rows support elimination.
3. Inspect material genealogy for a transition close enough to precede the signal. Treat timing as a hypothesis, not proof.
4. For each plausible changed lot, inspect incoming-inspection results and compare the measured value with both specification limits and disposition.
5. Conclude with separate cited claims for eliminated equipment, the relevant lot transition, and inspection confirmation. Implicate a cause only when the evidence chain connects its timing and condition to the signal.

Do not name a lot, supplier, or root cause until a registered tool returns that evidence.
